## 〇、落地契约（写给作家，拿到即可写成 JSON）

本设计书面向 `content/historical-figures/` 下的三个 JSON 文件。字段契约如下（本文件不写 JSON，只定规格）：

- **`types.json`**：`{ slug, dims:[{key,label}×4], types:[{ id, name, title, era, role, quote, theme:{accent,accent2}, tags:[3], dims:{guts,mind,heart,will}, desc:[3], rarityFactor, story, misread }] }`
- **`traits.json`**：`{ high:{guts,mind,heart,will}, low:{guts,mind,heart,will} }`
- **`questions.json`**：`{ questions:[{ q, opts:[{ t, w:{typeId:权重}, d:{guts,mind,heart,will} }×4] }] }`

**选项权重规则**：每个选项的 `w` 里，其主类型权重给 **2**（`build.mjs` 以 `o.w[k] >= 2` 判定主类型），可再给 0–1 个次要类型权重 1 作"第二人格"调味；其余类型不写。每个选项的 `d` 给四维贡献值 0–3，方向须与该选项对应人物的四维倾向一致（该人物高分维 → 给 2–3；低分维 → 给 0–1）。

**稀有度**：`rarityFactor` 乘在类型得分上，`< 1` 更稀有。目标分布见第二部分表格，`factor` 是起始值，最终以 `node scripts/build.mjs historical-figures` 跑出的分布表为准迭代，直到"最稀有 3–4%、最常见 15–18%"且无单一类型 > 30%。

## 一、四维设计

英文 key 沿用现有代码：`guts` / `mind` / `heart` / `will`。

| key | 中文标签 | 一句话定义 | 高分表现 | 低分表现 |
|---|---|---|---|---|
| `guts` | 胆魄 | 敢不敢在不确定里先迈一步——对风险与冲突的直面程度 | 抢着说"我来"，宁可做错也不愿错过 | 先观望，确认安全了才肯动 |
| `mind` | 谋略 | 遇事先想透再动还是凭直觉冲——认知加工与筹划的强度 | 别人还在上头，你已经把三条退路想完 | 凭直觉走，结果好坏认了就行 |
| `heart` | 深情 | 被情绪、他人、细节打动的程度——情感浓度与共情强度 | 能读出别人没说的那半句，也常为细节失眠 | 情绪靠后放，先处理事情再说 |
| `will` | 执念 | 对目标咬得多紧、放不放得下——动机强度与坚持力 | 认定的事，八头牛都拉不回来 | 样样都能沾，样样都不深 |

**心理学依据（内部用，不对外露一个术语）**：

这四维是把人拆成四条正交的轴：**行为激活（胆魄）— 认知加工（谋略）— 情感强度（深情）— 动机强度（执念）**。分别对应大五里"外向性的果断/活跃面""开放性 + 尽责性的审慎面""宜人性的移情面 + 神经质的感受面""成就动机 + 尽责性的坚持面"。

**为什么这样切**：关键在两组"解耦"——

1. **胆魄 ≠ 执念**。一个是"敢不敢冲"，一个是"放不放得下"。李白敢冲（胆魄高）但极易散（执念低）；王阳明不莽（胆魄低）但极有定力（执念高）。若把两者合并成"进取心"，这 10 个人会塌成一维。
2. **谋略 ≠ 深情**。一个是"算得清"，一个是"动不动心"。武则天谋略极高而深情极低；李清照深情极高但绝不糊涂。两者合一会分不开"理智派"与"情绪派"。

**区分度保证**：见第二部分"性格面向说明"。10 个人的四维签名各不相同，不存在两两几乎重合者（后文逐条给出最高维/最低维/决定性落差）。

## 二、10 个人物的人格原型

> `dims` 顺序固定为 `guts / mind / heart / will`。`quote` 除武则天、花木兰外均为原文；武则天、花木兰无单人原文金句，用化用句，意境以史料/《木兰辞》为准，不歪曲。
> **花木兰红线**：她是文学形象，非信史人物。`story` 与 `misread` 只取《木兰辞》已有内容（"阿爷无大儿"代父从军、"从此替爷征"、"将军百战死，壮士十年归"、"对镜帖花黄"、"安能辨我是雄雌"），禁止编造具体年代、战役、地名。

| 字段 | 说明 |
|---|---|
| id / name | 英文小写 / 中文名 |
| title | 称号 4–6 字，要有记忆点 |

| 一句话概括 | 性格核心 |

### 性格面向说明（10 人在四维空间如何彼此区分）

四维值不是装饰，每人都有一组"签名"（最高维 / 最低维 / 决定性落差）：

| 人物 | 签名 | 一句话区分 |
|---|---|---|
| 苏轼 | 谋略88 最高，执念50 最低 | 想得最透、也最不较劲，是"想得开" |
| 李白 | 深情92 最高，执念38 最低 | 情最满、欲最散，是"停不下来" |
| 辛弃疾 | 执念95·胆魄92 双高，谋略72 相对最低 | 全维度偏高，是"憋着一股劲" |
| 李清照 | 深情96 最高，执念62 | 情满且有硬骨，是"柔里带刚" |
| 王阳明 | 谋略96 最高，胆魄60 最低 | 想得最透、最不莽，是"心里有根" |
| 霍去病 | 胆魄98 最高，深情42 最低 | 敢冲、情淡，是"眼里只有目标" |
| 周瑜 | 谋略82 最高，深情64 最低 | 均衡的才将，是"有要求有分寸" |
| 项羽 | 胆魄96 最高，谋略32 最低 | 敢冲、不算，是"骄傲到底" |
| 武则天 | 执念100 最高，深情34 最低 | 欲极强、情极淡，是"为结果开路" |
| 花木兰 | 胆魄84 最高，谋略52 最低 | 实干担当、不纠结，是"默默扛事" |

最容易撞型的几对，都已被刻意拉开：

- **李白 vs 李清照**（同为"深情"高）：李白谋略 55、执念 38（散、疏于算计）；李清照谋略 78、执念 62（精、有骨）。差在"是不是拎得清"。
- **辛弃疾 vs 项羽**（同为"刚烈武将"）：差在谋略 72 vs 32——一个将才入词、一个有勇少谋。
- **辛弃疾 vs 霍去病**（同为"热血少年"）：差在深情 80 vs 42——一个重情、一个寡情。
- **项羽 vs 霍去病**（同为"胆魄近满分"）：差在深情 74 vs 42 与谋略 32 vs 52——一个重情不算、一个冷静寡情。
- **武则天 vs 王阳明**（同为"谋略极高"）：差在深情 34 vs 70 与胆魄 88 vs 60——一个为结果开路、一个守住内心。
- **花木兰 vs 周瑜**（同为"相对均衡"）：差在谋略 58 vs 82——一个实干不纠结、一个才情有分寸。

结论：四维空间里没有任何两人在全部四轴上接近，`dims` 可直接作为雷达图数据与 `d` 贡献方向。

## 五、细则方案

用于解决"不同答法撞同一结果"：细则 1 = 最高维画像，细则 2 = 最低维画像，细则 3 = 该类型的"别人怎么误读你"。组合 = 4×4×10 种，基本消除同质化。

**配比铁律：7 分看见 + 3 分提醒。** 下面每条均已内置一句温和提醒（不纯夸、不说教、不用"心理/诊断/评估/量表"字眼）。

### traits.high（四维高分画像，各一条）

- `guts`：你往往是第一个说"我来"的人，别人以为你天生胆大，其实你只是更怕遗憾、不怕丢脸。
- `mind`：你习惯在别人上头时已经想完了退路，只是这股"想清楚"的劲儿，偶尔会让你错过该莽一次的时刻。
- `heart`：你比谁都能捕捉到别人没说的那半句，所以常被细节打动，也常被细节拖累到半夜。
- `will`：你认定的事八头牛都拉不回来，只是有时候，放不下也会变成不肯放过自己。

### traits.low（四维低分画像，各一条）

- `guts`：你更愿意先看清楚再动，宁可慢半拍，也不想踩进自己没把握的坑。
- `mind`：你不爱把每件事都算得明明白白，更多时候跟着直觉走，结果好坏，认了就行。
- `heart`：你习惯把情绪往后放、先处理事情再说，只是别人有时会误以为你不在乎。
- `will`：你不缺冲劲，缺的是那股"非它不可"的执念，所以常常是样样都能沾，样样不深。

### misread（10 条，20–35 字）

- 苏轼：别人以为你心大、什么都不往心里去，其实你把难过都消化成了笑意。
- 李白：别人以为你吊儿郎当、不靠谱，其实你只是没法对不喜欢的事假装认真。
- 辛弃疾：别人以为你浑身是刺、太好强，其实你只是有股劲儿一直没找到出口。
- 李清照：别人以为你敏感脆弱，其实你比谁都硬气，只是把柔软留给了值得的人。
- 王阳明：别人以为你清高、不合群，其实你只是懒得跟解释不通的事耗下去。
- 霍去病：别人以为你冷漠、不近人情，其实你只是目标在前，暂时没空回头。

## 六、交接给作家 / 运营的注意事项

1. **`story`（时代小剧场）素材从 research.md 取**：苏轼=沙湖道中遇雨；辛弃疾=22 岁独闯金营擒叛徒之夜；李白=受召入京"仰天大笑出门去"当天；李清照=晚年独守金石书画；项羽=垓下别虞姬之夜。其余按人物张力自拟，但**事实必须落在 research.md 高可信度范围内**。
