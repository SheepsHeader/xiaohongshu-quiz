# 主题卡 · 你最像历史里的哪个人物

> 这是阶段⓪的产出，后面所有阶段的输入。本主题已完整实现，可作为新主题的参考范例。

## 基本信息

- **主题**：你最像历史里的哪个人物
- **一句话钩子**：你的性格，历史上早有人替你走完了——连代价都替你付过了
- **结果单位**：一个历史人物

## 知识域

- **主**：中国史学（人物生平、关键抉择、被误读的地方）
- **辅**：人格类型学（性格分型、行为倾向）
- **为什么是它**：结果要「像真的」，需要史料支撑人物性格；要「说得准」，需要一套能分人的框架。只靠史学分不出型，只靠类型学写不出质感。

## 结果形态（已选定方案）

- **结果单位**：一个历史人物
- **卡片叫什么**：人物卡
- **卡片包含**：姓名 / 称号 / 年代·身份 / 金句 / 三面剖析（性格·关系·事业）/ 四维坐标 / 被误读
- **叙事层**：**时代小剧场**——第二人称，把用户放进那个历史人物的一个具体瞬间（苏轼=沙湖道中遇雨，辛弃疾=22 岁闯金营）
- **口吻**：宿命感、古典、克制

## 维度设计

- **从**：人格类型学
- **切出**：胆魄 `guts` / 谋略 `mind` / 深情 `heart` / 执念 `will`
- **凭什么能分开**：靠两组解耦——胆魄≠执念（李白敢冲但极散，王阳明不莽但极定）、谋略≠深情（武则天算得清但情极淡，李清照情极满但不糊涂）。10 个类型两两之间至少一轴差 ≥25。

## 受众与口吻

- **人群**：十几岁到 30 多岁，女性约 75%、男性约 25%，学生与初入职场为主
- **口吻**：**宿命感、古典、克制**（不是说教，不是鸡汤）
- **该提**：不被理解的拧巴、性格带来的真实代价、与古人的共鸣
- **该避**：考据腔、诗词大会感、把人物当课本、「你这种人」的贴标签

## 差异化

- **竞品停在哪**：全部停在「人物名 + 一句话」的浅层，截图区只有名字和金句
- **我们多做的那一步**：**时代小剧场 + 被误读 + 四维坐标**。竞品给人一个标签，我们给人一段「你被放进那个时代会怎样」的叙事，以及「别人怎么误读你」的精准一击。

## 被淘汰的方案

> 说明：本主题在 HITL 机制建立前完成，以下是补做的方案复盘。

- **按命运切**
  - 内容：结果单位=人生结局类型，维度=顺逆 / 显隐 / 聚散 / 成败，叙事层=命运复盘
  - 淘汰原因：结局类型容易让人感到"注定"，情绪偏负面；且结局比性格更难在 20 题内测准，容易沦为瞎猜
- **按选择切**
  - 内容：结果单位=关键抉择原型，维度=进退 / 取舍 / 攻守 / 藏锋，叙事层=抉择现场
  - 淘汰原因：抽象度太高。用户测完拿到"进退型"这种名字没有身份代入感，也不好截图分享——**结果单位必须是一个能拿来当身份的东西**
