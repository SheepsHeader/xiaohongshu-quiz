# 《你最像历史里的哪个人物》主题研究报告

> 结论先行：**值得做，但必须换角度。** "你像谁"这个概念已被市场验证、也已被搬运烂大街；差异化只能压在**结果页的情绪深度 + 人物选择的独特性**上。

---

## 一、人群画像

### 谁最可能测【检索依据为主】

- **性别比显著高于基线。** 小红书历史人物赛道的核心是"史同女"文化，公众号文章标题即直接锚定人群："好一个'史同女'"、"年轻女孩，开始去坟头追星了"、"一名00后法学生，爱上'史同'"。**推断：女性占比约 85–90%，高于全局基线 70–80%。** 但历史题材同时有男性底子（武将/谋士向），骨架仍须中性。
- **年龄：00后为主，18–28 岁。** 检索多处出现"00后法学生""年轻女孩"，与大学生、初入职场人群重合。
- **状态：学生 / 未婚年轻职场。** 他们不把历史当知识学，而是当"同人素材""精神同类"，有稳定的表达与打卡习惯（线下"奔走在坟头"、二次创作）。
- **核心自我怀疑：** "我的拧巴、执拗、不被理解，是不是错的？"——爆款钩子"历史上早有人替你疯过"卖的正是"你不是异类，你的性格有伟大的原型"。**这决定题目场景必须落在他/她的真实内耗上**（不合群、慢热、想冲又怕、较真、情绪过载），而非历史知识问答。
- **他们形容自己的词：** "拧巴""疯""执拗""矫情""不甘"——来自爆款标题高频词（疯过、咬着牙走通、沉默）。文案语感应接"疯过""扛过""咬着牙"这类动作，而不是"优秀""自信"。
- **排斥：** 说教、考据腔、把人物当课本、"你这种人"的贴标签、廉价鸡汤式"加油你可以"。他们要的是"被一个伟大同类接住"，不是"被教育"。

## 二、竞品拆解

### 1. 小红书爆款笔记「你这种性格，历史上早有人替你疯过了」
- **结构（推断）**：短题（有笔记写"5道题"，另一条引流写"24道题"），选完评论区晒"答案组合"撞同款。
- **钩子**：身份钩子 + 宿命感，"你的性格 + 历史上早已有人替你 [完成了你不敢做的事]"。
- **截图区（关键）**：晒的是"答案组合 + 人物名"，靠评论区撞"同一前世"制造攀比。**推断：结果页首屏 = 人物名 + 一句人设金句，是唯一被截图/被引用的块。**

### 2. psycove「人格博物馆 · 你最像哪位古人 / 穿越回古代 / 前世身份」
- 已成产品线（同站多套测试），证明"古人/历史人格"是可规模化的付费心智。
- **结构（推断）**：标准题→结果页给"人物 + 一段画像"。视觉未获取，**推断为竖屏卡牌式结果页**（同类 H5 通用）。

### 3. tooljson「测一测你像哪位古人——历史上早有人按你的性格走完了一生」
- 与 psycove 同生态的现成工具，文案钩子同源（"早有人按你的性格走完一生"），说明该句式已被验证并快速复制。

### 4. 「20位古代文人 MBTI」中式 MBTI 系列（小红书多篇）
- 人物清单几乎全为文人：屈原、李白、杜甫、王维、白居易、李商隐、杜牧、苏轼、李清照、辛弃疾、陆游、柳永、欧阳修、王安石、柳宗元、韩愈、晏殊、秦观。
- **给我们的信号**：① 人物可选面极宽；② 纯文人向偏"文青女性"，但我们目标人群更年轻，应**混入少年英雄（霍去病、周瑜）、女性（武则天、李清照）、武将（辛弃疾、项羽）**，避免撞成"诗词大会"。
- 每型配一句对仗画像（如"李白：豪放洒脱思跳脱"），**证明"称号 + 一句话"是结果页的记忆锚点**。

### 5. HPTI「你的历史人格索引」App / 「你是哪个历史人物」App
- 有独立 App，说明赛道真实存在、且有人愿为此装 App；但**App 是过度产品化**，我们的机会恰在"不装 App、发得出去的纯静态长图"。

> 竞品共性判断【推断】：结构都是"短题→单结果人物卡"；**截图截的是"人物名 + 称号 + 一句金句"的首屏**，没有一家把"时代小剧场/被误读/多维画像"做深——这就是我们的差异化位。

### 可改写的瞬间（时代小剧场候选）
- 苏轼：1082 年沙湖道中遇雨，"同行皆狼狈，余独不觉"——**具体到一场雨**，天然是结果页情绪高点。
- 辛弃疾：22 岁独闯金营擒叛徒的那个夜。
- 李白：受召入京"仰天大笑出门去"的那天。
- 李清照：晚年独自守着一屋子金石书画。
- 项羽：垓下四面楚歌、别虞姬的一夜。

### 可用的冲突（张力 / 被误读）
- **苏轼**：旷达 × 一生被贬（天才被命运反复碾压，仍笑着走）。
- **辛弃疾**：词人 × 将才（满身武艺，只能写进词里，"可怜白发生"）。
- **周瑜**：被《三国演义》误读成"气量狭小"× 史实"雅量高致"——**"被误读"的完美原型**。
- **李清照**：婉约 × 刚烈（写最柔的词，说最硬的话）。
- **武则天**：被骂千年 × 无字碑任人评。
- **项羽**：宁折不弯 × 不懂变通（英雄的骄傲 = 失败的原因）。

## 四、传播角度

### 会点进来的标题【检索依据，已现成套路】
- 已验证公式：**「你的性格 + 历史上早已有人替你 ____」**（疯过 / 走通了这条路 / 付出了代价 / 按你的性格走完了一生）。
- 反差/悬念型："测完我沉默了，我居然像这个历史人物"、"你的性格是历史上谁的复刻版"。
- **结论**：钩子不缺，缺的是结果页质量——标题把人骗进来，结果页留不住人就是一次性流量。

### 会被转发的截图【推断】
- 转发动力 = "这张卡说得就是我，且别人看了会羡慕/想测"。因此截图区必须：**人物名 + 称号 + 一句能单独成立的金句**，且带稀有度（"全国仅 X%"）制造攀比。长图需带回流位（"你也来测"），否则裂变断链。

### 热度与烂大街程度【检索依据】
- 热度真实且高：同一选题多个账号重复搬运（"你这种性格，历史上早有人替你疯过了"至少出现 3–4 篇），已有 psycove/tooljson/HPTI 等现成工具，微信亦有"你像谁比'你是什么型'更戳人"的讨论。
- **但烂大街的是"概念 + 标题"，不是"结果页情绪"。** 现有一律停在"你像谁 + 一句话"，没人做深，我们的 20 题 + 时代小剧场 + 被误读 + 四维图 是空位。

## 五、可行性判断

**结论：值得做，但必须换角度——从"你像谁"升级为"你的性格早已有人替你走完了这一生，连代价都替你付过了"。**

理由：
1. **需求已验证、人群清晰**：史同女/00后女性真实存在，且愿意为"被同类接住"买单。
2. **竞品全停在浅层**：截图只截"人物名+一句话"，情绪深度和"被误读"无人做——这是可持续的差异化。
3. **风险可控**：唯一翻车点是历史事实（错年代/错金句出处会被评论区当场抓），已用可信度分级兜底；解读层自由抽象（如周瑜只取"被误读"原型，不评"既生瑜何生亮"）。

**下一步给模型师的硬约束：**
- 人物池建议 10 个，**混性别与身份**：苏轼、李白、辛弃疾、李清照、王阳明、霍去病、周瑜、项羽、武则天、屈原（或张良）。避免全文人。
- 场景题必须落在"年轻女性的真实内耗"，**禁止任何历史知识问答**（会劝退核心人群）。
- 结果页截图区 = 人物名 + 称号 + 金句 + 稀有度，一屏内成立；深度区才是时代小剧场。
